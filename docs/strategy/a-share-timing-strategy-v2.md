版本：v2.0（研究与实施初稿）
日期：2026-10-18
来源：Astra《A 股技术择时策略 v1.0》提供执行骨架（时间口径、买入模型 A/B、价格约束、退出系统、持仓状态、验证反例）；「四层漏斗」方案提供否决门、情绪温度、默认仓位、模型层、证据表。

## 0. 与 v1.0 的关系

| 维度 | Astra v1.0 | v2.0 |
|---|---|---|
| 定位 | 纯技术择时；候选池由外部提供，风险筛选在池外 | 择时 + 把 A 股特有的风险筛选（否决门）内置为第一层，候选池进来先过门 |
| 市场环境 | 结构状态（基准 + 广度） | 结构状态决定能否新增（沿用）；新增情绪温度，只决定风险预算乘数 |
| 买入模型 | A 回调、B 突破 | 沿用，少量修正（结构低点口径、回调深度上限、确认日量能、涨停突破的竞价规则） |
| 价格约束 | RR ≥ 2、E_max | 原样沿用，补充 P_target 的确定规则 |
| 仓位 | 不规定，由用户账户预算决定 | 给出默认仓位规则，用户可覆盖 |
| 退出 | 六级退出 | 原样沿用，加否决门事件触发的退出复核 |
| 模型（LLM） | 只提到评分不替代规则 | 单列一层：四项任务、输出 JSON、只能降级和标记，不能产生买入 |
| 输出 | 必需信息表 | 证据表（字段固定、含 JSON schema） |
| 实现 | 提到 DSA 边界 | 映射到 Vibe-Research 后端现有端点，列出缺口与分阶段计划 |

## 1. 总体结构

```text
L0 数据与口径         完整日线、复权、固定基准、固定板块
    ↓
L1 否决门             命中 → 不新增；持仓命中 → 退出或减仓复核
    ↓
L2 市场环境           结构状态（顺风 / 分化 / 逆风 / 未知）→ 能否新增、总仓位上限
                      情绪温度（高 / 中 / 低 / 冰点 / 未知）→ 风险预算乘数
    ↓
L3 板块与个股         固定板块 RS20、板块广度；个股 RS20、孤立异动
    ↓
L4 入场模型 A | B     触发价 E_trigger、初始止损 S
    ↓
L5 价格约束           成本后 RR ≥ 2、最高接受价 E_max、有效期
    ↓
L6 仓位               风险预算 × 乘数 → 股数；单票、板块、总仓位上限
    ↓
L7 持仓退出           原止损 → 趋势破坏 → 盈利保护 → 时间退出 → 降速减仓 → 持有或加仓
    ↓
L8 模型层             事件核验、论点与失效条件、反方论证、一致性校验
    ↓
L9 证据表             每只股票一张，字段固定
```

五条原则：

1. **代码判定，模型解释。** 所有买卖触发由 L1–L7 的可复算规则决定；模型只读文本、写论点、找矛盾。
2. **先管存量，再找增量。** 每日先跑持仓批次，再跑候选批次。
3. **阈值相对化。** 价格距离用 ATR14 表达，活跃度用个股自身 250 日分位表达，少用固定百分比。
4. **一次只用一个口径。** 回调窗口、整理窗口、盈利保护方式各只选一种；变体进入回测对照，不在单次分析中挑最有利的。
5. **缺失即未知，未知不执行。** 任何关键字段缺失时输出「未知」并列出缺失项，不用默认值代替。

## 2. 数据、时间与口径

### 2.1 时间定义（沿用 v1.0）

- `T`：最新完整交易日。`D1`：T 之后的下一实际交易日。
- T 日收盘后生成 D1 的条件计划。非交易日只能复核，不得把上一交易日信号写成当天新信号。
- 未完成的盘中 K 线只能生成暂定观察，不能确认突破或收盘破位。
- 每份输出写明：分析时刻、最新完整日线日期、报价时刻、计划适用交易日。

### 2.2 指标定义

```text
C_t, H_t, L_t, V_t, Amt_t : 第 t 日收盘、最高、最低、成交量、成交额

MA_n(t)        = 最近 n 个完整交易日收盘的算术平均
MA20 上行      = MA20(T) > MA20(T-5)；下行反之
TR_t           = max(H_t - L_t, |H_t - C_(t-1)|, |L_t - C_(t-1)|)
ATR14(T)       = 最近 14 日 TR 的算术平均（简单平均，不用 Wilder 平滑）
ATRpct(T)      = ATR14(T) / C_T
Ret_n(X,T)     = C_X(T) / C_X(T-n) - 1
RS_n(X,T)      = Ret_n(X,T) - Ret_n(固定基准, T)
CloseLoc(T)    = (C_T - L_T) / (H_T - L_T)；H_T = L_T 时记不可用
V20(T)         = mean(V_(T-20) ... V_(T-1))，不含 T 日
Amt20(T)       = mean(Amt_(T-20) ... Amt_(T-1))
Pctl250(x)     = x 在该股最近 250 个完整交易日自身序列中的分位（0–1）
```

**结构低点 `L_struct`（新增，固定算法）**

```text
d_hi     = [T-20, T-1] 内最高收盘所在日
L_struct = min(C_t), t ∈ [d_hi-20, d_hi-1]，连同其日期一起输出
若 d_hi 之前不足 20 个交易日数据 → L_struct 不可用，A 模型只观察
有效破坏 = 任一日收盘 < L_struct
```

> 说明：v1.0 要求结构低点「写明日期、不得反复下移」，但没有给算法。固定算法后，结构低点不随分析者的看多意愿变化。

### 2.3 固定基准与固定板块

- **固定基准**：每个候选池在入池时指定一个宽基指数并写入记录，默认中证全指（000985）。本次交易期间不切换。
- **固定板块**：入池时指定一个行业口径（申万一级，或东财行业板块），写入 `sector_fixed`。概念板块只作为模型层的背景信息，不参与 L3 判定。
- 多标签股票只用 `sector_fixed`，不得事后套入当天最强主题。

### 2.4 复权与可交易价格（沿用 v1.0）

- 趋势、均线、RS、结构比较使用同一前复权口径；执行价换算为当日实际可下单价格。
- 除权除息、拆合股、数据源切换后，E0、S0、S_effective、L_struct、R_box 必须重新映射；无法映射时暂停精确执行价。
- 回测不得使用当前复权结果、当前行业成分或当前存续股票重建历史。

## 3. 第 1 层：否决门（新增）

对候选池中每只股票和每只持仓，每日重算。表中「新增」列是对新开仓和加仓的处理，「持仓」列是对已有仓位的处理。

| 编号 | 条件 | 判定口径 | 新增 | 持仓 |
|---|---|---|---|---|
| G1 | ST / *ST / 退市整理 | 证券简称含 ST，或交易所风险警示标识 | 否决 | 退出复核 |
| G2 | 面值退市风险 | C_T < 1.5 元 | 否决 | 退出复核 |
| G3 | 立案调查 / 重大行政处罚 | 近 180 日公告标题含「立案」「调查通知书」「行政处罚决定」 | 否决 | 次日退出复核 |
| G4 | 审计意见非标 | 最近年报为保留、否定、无法表示意见；带强调事项段 → 降级 | 否决 / 降级 | 减仓复核 |
| G5 | 解禁压力 | 未来 30 个交易日内实际可流通解禁股数 / 流通股本 ≥ 5%；2–5% → 降级 | 否决 / 降级 | 标记，禁止加仓 |
| G6 | 减持 | 近 90 日有董监高或 5% 以上股东减持计划公告，或减持正在实施 | 否决 | 禁止加仓；持仓期间新出现 → 降速减仓 1/3 复核 |
| G7 | 质押 | 第一大股东质押比例 ≥ 50%，或全部质押股数 / 总股本 ≥ 30% | 否决 | 标记 |
| G8 | 商誉 | 最近报表商誉 / 归母净资产 ≥ 30% | 否决 | 标记 |
| G9 | 盈利质量 | 最近两个年度经营现金流净额 / 归母净利润均 < 0.5，且净利润 > 0 | 降级 | 标记 |
| G10 | 持续亏损 | 最近两个年度归母净利润均 < 0，且最近年报营收 < 3 亿元 | 否决 | 退出复核 |
| G11 | 流动性 | Amt20(T) < 1 亿元 | 否决 | 标记，退出时分批 |
| G12 | 近期跌停 | 近 20 日出现收盘跌停（按该股当日跌停价判定） | 否决 | 标记 |
| G13 | 停牌或交易状态异常 | 当日无有效成交或处于停牌 | 否决 | 不计算 |
| G14 | 业绩披露窗口 | 处于预告或定期报告披露期，去年同期或最近一期累计亏损，且本期尚未披露 | 降级为观察 | 标记 |

处理规则：

- **否决**：不生成 A/B 计划；证据表写明命中项与数据日期。
- **降级**：风险预算乘数额外 ×0.5，B 模型停用，A 模型可评估。
- **未知**：某项数据缺失记「未知」。关键项（G1、G5、G6、G11、G13）任一未知 → 不新增。其他项未知数 ≥ 2 → 整股降级。
- 否决门结果不改变 L7 的退出规则；持仓列的「复核」指进入 L7 流程并在汇总中置顶。

> 说明：A 股散户的大额亏损多来自解禁减持、财务暴雷、流动性陷阱和退市，不来自均线看错。v1.0 把这类筛选留给外部候选池，v2.0 把它放进策略，是因为候选池方案和择时方案常由不同人维护，门槛不在策略里就没有人保证它一定被执行。

## 4. 第 2 层：市场环境

### 4.1 结构状态（沿用 v1.0）

广度样本：全部沪深 A 股，排除 ST、停牌、上市不足 60 日。

```text
Breadth20(T) = 样本中 C_T > MA20 的股票数 / 有效样本数
```

| 状态 | 判定 | 新增许可 | 总仓位上限 |
|---|---|---|---|
| 顺风 | 基准 C > MA20，MA20 上行，Breadth20 > 50% | A、B 均可评估 | 100% |
| 分化 | 数据完整，既非顺风也非逆风 | 仅 A，且须通过板块确认；B 观察 | 60% |
| 逆风 | 基准 C < MA20，MA20 下行，Breadth20 < 40% | 不新增，不加仓 | 不强制减仓 |
| 未知 | 基准或广度数据不可靠 | 不新增 | — |

- 结构状态不否决任何已触发的退出条件。
- 状态变化后，未执行的新开仓与加仓计划作废并重新评估。

### 4.2 情绪温度（新增）

数据来源：T 日收盘后的涨停池、炸板池、跌停池、昨日涨停池，以及全市场涨跌家数。

```text
ZT        = 涨停家数（优先用非一字的真实涨停）
DT        = 跌停家数
MaxBoards = 最高连板数
BreakRate = 炸板家数 / (涨停家数 + 炸板家数)
PromoRate = 今日 2 板及以上家数 / 昨日涨停家数
UpRatio   = 上涨家数 / (上涨 + 下跌 + 平盘)
```

| 温度 | 判定（按顺序匹配，先命中先定） | 乘数 m_sent |
|---|---|---|
| 未知 | 四池或涨跌家数任一缺失 | 0.5 |
| 冰点 | (MaxBoards ≤ 2 或 ZT ≤ 25) 且 (BreakRate ≥ 0.50 或 DT ≥ ZT) | 0.25 |
| 高温 | ZT ≥ 80 且 MaxBoards ≥ 5 且 BreakRate ≤ 0.30 且 PromoRate ≥ 0.30 | 1.0 |
| 低温 | ZT < 50，或 BreakRate > 0.40，或 DT > 0.5 × ZT | 0.5 |
| 中温 | 其余 | 0.75 |

附加规则：

- **过热预警**：高温连续 ≥ 5 个交易日，且当日 BreakRate 比其 5 日均值高 ≥ 0.15 → 标记「情绪见顶风险」，B 模型本日停用，A 模型乘数按 0.75。
- 情绪温度只改变 L6 的风险预算乘数，不改变 4.1 的新增许可。逆风时即使高温也不新增。
- 温度未知时照常输出结构状态，并在证据表披露缺失项。

> 说明：Breadth20 稳健但反应慢；涨停池数据直接反映 A 股短线资金的参与度，领先 1–3 天，但噪声大。把它限定为乘数而不是许可，是为了利用它的领先性，又不让一天的噪声否决整个结构判断。

### 4.3 合成

```text
能否新增    ← 结构状态（4.1）
允许的模型  ← 结构状态 + 板块确认（L3）+ 否决门降级（L1）
风险预算    ← 基础风险 r × m_sent × 降级系数（L6）
```

## 5. 第 3 层：板块与个股确认

### 5.1 板块确认

1. `sector_fixed` 的 RS20 > 0。
2. 板块广度：成分股中 C_T > MA20 的比例 ≥ 50%，有效成分股 ≥ 5 只。覆盖不完整时标记不确定。
3. **退潮观察**（新增）：板块 RS5 连续 3 日下降，或板块广度 < 40% → 标记退潮观察。此时 B 模型停用；A 模型要求个股 RS5 > 0。
4. **可选证据**（不参与许可，只进证据表）：板块内近 3 日涨停家数 ≥ 3。

### 5.2 个股确认

- 个股 RS20 > 0 为新开仓初始要求；同时列出个股 RS5、板块 RS5。
- **孤立异动**（给出算法）：T 日个股涨幅 ≥ 5%，V_T / V20 ≥ 2，而板块当日涨幅 ≤ 0 且板块上涨家数占比 < 50% → 标记。孤立异动不算板块共振，B 模型不接受。
- 公告与新闻只用于核验（L8），不单独产生买入。
- 重大负面信息未核清 → 新增计划降为观察。

## 6. 买入模型 A：缩量回调后再次走强（主模型）

### 6.1 趋势门槛

- MA20(T) > MA20(T-5)。
- C_T > MA20(T)。
- L_struct 可用，且回调段内无任何一日收盘 < L_struct。
- 通过 L1、L2、L3。
- **新增**：(C_T − MA20(T)) ≤ 3 × ATR14(T)。超过则视为远离均线的反弹，不按回踩处理。
- **新增**：若 MA60(T) < MA60(T-10) 且 C_T < MA60(T) → 只观察。
- 不要求 MA5 > MA10 > MA20 始终成立。

### 6.2 回调与量能

**默认口径 A1（固定窗口，沿用 v1.0）**

```text
回调段      : T-3 至 T-1
比较段      : T-8 至 T-4（5 日）
回调价差    : C_(T-1) < C_(T-4)
此前上涨    : C_(T-4) > C_(T-8)
V_pull      = mean(V_(T-3), V_(T-2), V_(T-1))
V_before    = mean(V_(T-8) ... V_(T-4))
缩量要求    : V_pull / V_before ≤ 0.70
回调深度    : C_(T-4) - min(L_(T-3), L_(T-2), L_(T-1)) ≤ 2.5 × ATR14(T)   （新增）
```

**研究口径 A2（自适应窗口，回测对照用，不与 A1 同时启用）**

```text
d_hi        = [T-10, T-1] 内最高收盘所在日
回调段      : d_hi+1 至 T-1，长度 n，要求 2 ≤ n ≤ 7
比较段      : d_hi-4 至 d_hi（5 日）
缩量要求    : mean(V 回调段) / mean(V 比较段) ≤ 0.70
回调深度    : C_(d_hi) - min(L 回调段) ≤ 2.5 × ATR14(T)
```

- 回调段各日收盘不得低于各自 MA20。
- 缩量只陈述「卖出活动减弱」，不写成「主力洗盘」。

### 6.3 再次走强确认

T 日必须收阳（C_T > O_T），并满足以下至少一项：

- C_T > MA5(T)；
- C_T > H_(T-1)。

**新增**：V_T ≥ V_pull。确认日量能低于回调均量的，记为「弱确认」，只观察。

### 6.4 初始止损与 D1 计划（沿用 v1.0）

```text
L_pull    = min(L 回调段 ∪ {L_T})
S_A       = L_pull - 0.3 × ATR14(T)，按价格档位向下取整
E_trigger = H_T + 1 个价格档位
```

- D1 只在价格到达 E_trigger 且不超过 E_max（第 8 节）时考虑执行。
- D1 先触及 S_A → 计划作废，不因随后反弹重新启用。
- D1 一字涨停开盘 → 不可成交，计划作废。
- D1 未触发 → 计划到期，下一完整日线重新评估。

## 7. 买入模型 B：整理收缩后的有效突破（辅助模型）

### 7.1 整理结构

仅在结构状态为顺风、板块与个股确认通过、板块未处于退潮观察时生成可执行候选。

```text
整理窗口    : T-15 至 T-1（默认 15 日；研究范围 10–30 日，单版本只用一个）
R_box       = max(H_(T-15) ... H_(T-1))
B_box       = min(L_(T-15) ... L_(T-1))
区间宽度    : (R_box - B_box) / B_box ≤ 20%                         （新增，平台可识别性）
触碰上沿    : 窗口内 H_t ≥ R_box - 0.5 × ATR14(T) 的交易日数 ≥ 2    （新增）
整理前上涨  : C_(T-16) > C_(T-36)                                    （新增，排除下跌中继）
TR_recent   = mean(TR_(T-5) ... TR_(T-1))
TR_early    = mean(TR_(T-15) ... TR_(T-6))
波动收缩    : TR_recent / TR_early ≤ 0.80
```

列出区间上下沿、起止日期、触碰上沿的日期。任一条件不满足 → 只观察。

### 7.2 突破确认

```text
C_T > R_box
V_T / V20(T) ≥ 1.5
CloseLoc(T) ≥ 0.70
```

- 量能 ≥ 2 倍只作描述，不提高仓位。
- 盘中越过 R_box、收盘回到区间内，不构成确认。
- **涨停突破**：信号成立，执行受限，进入 7.3 承接观察。

### 7.3 承接与入场（沿用 v1.0，补充竞价规则）

- 突破后 1–3 个交易日内观察回踩。
- `S_B = R_box − 0.3 × ATR14(突破日)`。承接确认前价格触及 S_B → 本次突破计划作废。
- **仅有日线时**：等待后续完整日线满足「最低价与 R_box 的差 ≤ 0.3 × ATR14(突破日)、收阳、收盘 > R_box」，以该确认日 H + 1 档作为下一交易日触发价。
- **有集合竞价数据时（可选扩展）**：突破次日 D1，若竞价高开 2%–6% 且竞价成交量 ≥ 突破日全天成交量的 5% → 可在 E_max 内执行；高开 > 7% 或低开 → 放弃本日，继续承接观察。没有竞价数据时不得使用本条。
- 3 个交易日内未形成承接，或价格持续远离突破位 → 结束观察，须形成新结构才能重建计划。

## 8. 价格约束：目标、成本、最高接受价（沿用 v1.0，补充 P_target 算法）

### 8.1 目标价 P_target

```text
摆动高点  : H_t 为其前后各 3 个交易日中的最高者
P_target  = 最近 120 个交易日内，高于 E_trigger 的最近一个摆动高点
```

- 无符合条件的摆动高点（创新高交易）→ 归入**独立观察组**，不编造目标通过 RR 门槛。独立观察组的 ATR 目标法（P = E + 2.5 × ATR14）列为 v2.1 研究项。
- 写出 P_target 的日期与复权口径。

### 8.2 成本与风险收益

```text
f        = 0.003（往返手续费 + 印花税 + 滑点的保守估计；已知更高时用更高值）
F        = f × E
Risk     = E - S + F
Reward   = P_target - E - F
RR       = Reward / Risk ≥ 2.0

E_RR_max    = (P_target + 2 × S) / (3 + 3 × f)
E_chase_max = E_trigger + 0.3 × ATR14(确认日)
E_max       = min(E_RR_max, E_chase_max)，按价格档位向下取整
```

- E_max < E_trigger → 无可接受买入区间，降为观察。
- 只在真实可成交价位于 `[E_trigger, E_max]` 内时考虑执行。
- 固定最低佣金等非线性费用按实际股数重算 RR。
- 跳空、价差显著扩大、重大事件后重新评估。

### 8.3 同股多信号与有效期（沿用 v1.0）

- A、B 同时成立只选一个主模型并记录理由。
- 所有未执行计划有到期日。
- E_max、S、P_target 发布后不因价格接近而临时修改；实质信息变化生成新版本。

## 9. 第 6 层：仓位（新增默认规则，用户可覆盖）

### 9.1 参数

| 参数 | 初值 | 含义 |
|---|---|---|
| NAV | 用户提供 | 账户净值 |
| r | 0.75% | 单笔计划风险占 NAV 的比例（研究范围 0.5%–1.0%） |
| m_sent | 见 4.2 | 情绪温度乘数 |
| m_gate | 1.0 / 0.5 | L1 无降级 / 有降级 |
| cap_stock | 20% NAV | 单票市值上限 |
| cap_sector | 40% NAV | 同一 `sector_fixed` 市值上限 |
| cap_total | 见 4.1 | 总持仓市值上限 |
| max_new_per_day | 2 | 每日新开仓上限 |
| max_positions | 8 | 同时持仓上限 |

### 9.2 股数

```text
Risk_per_share = E_max - S + f × E_max          （按最差可接受成交价计风险）
Q_raw          = r × NAV × m_sent × m_gate / Risk_per_share
Q              = floor(Q_raw / 100) × 100       （科创板按 200 股起、1 股递增规则另算）
```

- `Q × E_max > cap_stock × NAV` → 按 cap_stock 缩减。
- 加入后板块市值 > cap_sector，或总市值 > cap_total → 缩减或放弃。
- 缩减后 Q < 最小申报单位 → 不执行。
- 可用资金只计真实可用；计划卖出未成交前不计入。
- NAV 或持仓数据缺失 → 只输出价位，不输出股数。

> 说明：v1.0 认为择时与账户承受力是两个问题，这一点正确。v2.0 给出默认值是为了让流程能端到端跑通；用户账户有自己的预算时，以用户预算为准。

## 10. 第 7 层：持仓退出系统

### 10.1 处理顺序（沿用 v1.0，加第 0 级）

```text
0. 否决门事件（G3 / G6 / G10 新命中）→ 退出复核
1. 原止损或原结构失效
2. 趋势破坏
3. 已生效的盈利保护
4. 时间退出
5. 趋势降速减仓
6. 持有或条件加仓
```

- 退出优先于减仓，减仓优先于加仓。
- 当天没有新买点不自动产生卖出。
- 评分、热点、基本面评价、模型论点都不能覆盖已确认的退出条件。

### 10.2 原止损与原结构失效（沿用 v1.0）

- 按入场时确认的触发方式判断（盘中硬止损或收盘止损），不静默切换。
- 跌破该笔交易依赖的回调低点、承接结构或 L_struct → 按原计划处理。
- 止损只能依规则收紧，不能下移。
- 盘中触及但收盘收回 → 报告「曾触发，核对执行」。
- 跳空穿越 → 按实际可得价格评估。

### 10.3 趋势破坏（沿用 v1.0）

默认口径 **X1**：连续两个完整交易日 C < MA20，且个股 RS5 < 0。
研究口径 **X2**：单日放量（V ≥ 1.5 × V20）跌破 MA20。两者进入回测对照。

或：原突破结构失败，价格重回平台并触发原计划的结构失效条件。

### 10.4 盈利保护（沿用 v1.0 的 V1 为默认）

```text
R0            = E0 - S0（冻结）
启动条件      : 入场后最高收盘 H_close ≥ E0 + 2 × R0
S_suggested   = max(S_effective, H_close - 2 × ATR14(T))
```

- 只在 E0、S0 可信且 R0 > 0 时使用。
- S_suggested 是建议，确认后才成为 S_effective；新建议低于现有保护位时保持原位。
- 建议位高于当前报价 → 报告「保护条件已被穿越」，进入退出复核。

研究口径 **V2**：H_close ≥ E0 + R0 时减持 1/3，剩余按 MA10 跟踪。V1、V2 只选一个运行，另一个进回测对照。

### 10.5 时间退出（沿用 v1.0）

- 买入日记第 0 日。
- 第 5 个交易日：H_close < E0 + 0.5 × R0 且 RS5 < 0 → 建议减持 1/3。
- 第 10 个交易日：H_close < E0 + R0 且 C_T < MA10 → 建议退出剩余可卖部分。
- 同一 position_id 的同一时间事件只执行一次。
- R0 或入场日期不可靠 → 不触发，改人工复核。

### 10.6 趋势降速减仓（沿用 v1.0）

同时满足：连续两日 C < MA10；个股 RS5 < 0；`sector_fixed` RS5 < 0 → 建议减持 1/3。

- 与时间减仓同日触发只减一次。
- 执行后，连续两日收盘重新站上 MA10 之前不重复触发。

### 10.7 持仓状态字段（沿用 v1.0）

position_id、股票代码、快照时间、当前数量、可卖数量、真实成本、E0、入场日期、入场模型、S0、S_effective、止损触发方式、已执行与待执行事件、各加仓批次（入场价、日期、止损）。

- 未知字段记未知，不当 0。
- 只有真实成交或明确确认才能更新状态。「建议卖出」不等于已卖出。

---

## 11. 加仓规则（沿用 v1.0，补一条）

全部满足才生成加仓计划：

1. 原逻辑成立，无退出、减仓或待核对止损事件。
2. 结构状态允许新增；板块与个股确认通过；L1 无新命中。
3. 出现新的 A 或 B 信号，不沿用旧买点。
4. 新增部分独立满足触发价、E_max、初始止损、RR。
5. 加仓后账户风险、现金、集中度仍合规。
6. 新批次有独立记录。
7. **新增**：新批次股数 ≤ 首批股数的 50%（只做递减金字塔）。

禁止：低于成本加仓；为迁就新批次下移旧批次止损；重复生成同一信号的执行指令。

## 12. 第 8 层：模型层（新增）

### 12.1 输入

- L1–L7 产出的证据表草稿（结构化字段）。
- 近 30 日公告标题与摘要、近 7 日个股新闻、互动易问答（可选）、研报摘要（可选）。
- 每条文本必须带日期；无日期的文本标记为「不可定位」，不得作为依据。

### 12.2 四项任务与输出格式

**任务 1 事件核验**：对每条公告或新闻输出

```json
{"date": "2026-10-15", "event_type": "减持|解禁|业绩|订单|政策|监管|回购增持|其他",
 "direction": "正|负|中性|不明", "materiality": 1,
 "source_reliability": "公告|主流媒体|自媒体|不明",
 "already_priced": false, "affects_gate": ["G6"]}
```

`already_priced`：事件披露日前 10 个交易日累计涨幅 ≥ 15% → true。`affects_gate` 非空时，代码层重新核对对应否决门。

**任务 2 论点与失效条件**：3 句论点，只能引用证据表中的字段；3 条失效条件，每条映射到可计算检查，例如「收盘 < S_A」「`sector_fixed` RS5 连续 3 日 < 0」「出现 G6 公告」。

**任务 3 反方论证**：至少 3 条反对理由。若任一条引用了 L1 的某个条件而代码判定为未命中 → 输出 `review`（可能是数据缺失）。

**任务 4 一致性校验**：逐条检查以下组合，命中则输出对应标记：

| 组合 | 标记 |
|---|---|
| 放量上涨 + 90 日内减持公告或 30 日内解禁 | downgrade |
| 突破确认 + 利好事件 already_priced = true | downgrade |
| 回调中 + 处于 G14 披露窗口 | observe |
| 新闻题材与 `sector_fixed` 不符且涨幅由题材驱动 | observe（孤立异动复核） |
| 文本证据全部无日期 | 记「无可用文本证据」，不降级 |

### 12.3 权限边界

```text
llm_flags ∈ {none, downgrade, observe, review}
downgrade → m_gate 额外 ×0.5
observe   → 本次不执行，保留计划待复核
review    → 人工复核，不执行
```

- 模型不能产生买入、不能给出价格、不能提高置信度、不能修改 L1–L7 的任何数值。
- 无文本数据时输出「无文本证据」，不臆测，不因缺失而降级。
- 模型输出中出现「建议买入」「目标价」等字段 → 丢弃该输出并记录违规（见 17.1 第 11 条）。

### 12.4 提示词要点

- 系统提示写明：你只执行四项任务；输出 JSON；每条引用带日期；禁止价格与买卖建议。
- 把证据表作为唯一事实来源注入；文本证据分块注入并标注来源与日期。
- 一次只处理一只股票。

## 13. 第 9 层：证据表

每只股票每日一张。字段顺序固定，便于比对与审计。

| 分组 | 字段 |
|---|---|
| 身份 | code、name、role（持仓 / 候选）、position_id、sector_fixed、benchmark_fixed |
| 时间 | analysis_time、last_bar_date、quote_time、plan_date（D1） |

## 14. 每日工作流

### 14.1 持仓批次（先跑）

```text
核对持仓快照与真实成交记录
    ↓
L1 否决门重算 → 命中 G3 / G6 / G10 置顶
    ↓
原止损与可卖限制（T+1）
    ↓
趋势破坏、盈利保护、时间退出、降速减仓
    ↓
L8 模型层（只读，输出标记）
    ↓
剩余持仓：持有或条件加仓
```

### 14.2 候选批次

```text
核对候选有效期，剔除已持有
    ↓
L1 否决门 → 否决者直接写证据表，不再往下
    ↓
L2 结构状态与情绪温度（全市场只算一次）
    ↓
L3 板块与个股确认
    ↓
L4 分别判断 A、B，选一个主模型
    ↓
L5 触发价、止损、目标、E_max
    ↓
L6 股数与集中度
    ↓
L8 模型层 → 可能降级或改为观察
    ↓
形成 D1 条件计划或观察结论
```

### 14.3 汇总顺序

1. 已触发或迫近的持仓风险（含否决门新命中）。
2. 待执行的退出、减仓与不可卖限制。
3. 继续持有与保护位调整建议。
4. 条件加仓与候选开仓计划，统一核对账户额度。
5. 因否决、价格、数据、环境或结构不合格而不执行的项目，附原因。

### 15.3 DSA 与 Hermes 的接入边界

- **DSA 自然语言策略 YAML 只能引导模型，不能强制执行规则。** v2.0 在 DSA 里的 YAML 只写两件事：「以证据表为唯一事实来源」和「只执行第 12 节的四项任务」。

- Hermes 调用时须实际提供持仓快照与候选池；无法注入时，输出保留人工复核标记，不伪装已强制执行。

## 17. 验证

### 17.1 先验证运行正确性（反例，全部必须通过）

v1.0 的八条：

1. 止损已触发但模型评分仍高 → 必须优先报告退出。
2. 突破成立但开盘价 > E_max → 必须放弃。
3. 候选已持有 → 转持仓流程，不重复开仓。
4. S0 未知 → 不得编造 R 倍数与时间退出结论。
5. 当日新增股份不可卖 → 正确反映 T+1。
6. 同一降速事件已减仓 → 次日不得默认再减。
7. 最新日线过期 → 不得生成当日完整 K 线确认。
8. 盈利保护位已高于现价 → 报告已穿越，不伪装未触发。

v2.0 新增：

9. 否决门命中（例如 20 日内解禁 8%）但 A 形态完美 → 不得生成计划。
10. 情绪数据缺失 → 乘数 0.5 并披露，不得默认高温。
11. 模型层输出含「建议买入」或价格 → 丢弃并记录违规。
12. 多标签股票当天最强概念 ≠ `sector_fixed` → 只用 `sector_fixed`。
13. 复权切换日 → S_effective、L_struct、R_box 映射正确，不触发假破位。
14. D1 先触及 S_A 后触及 E_trigger → 计划作废。
15. 逆风 + 高温 → 不新增。
16. 板块退潮观察 → B 模型不得生成计划。

### 17.2 再验证交易效果

- 分别统计 A、B；按结构状态和情绪温度分组。
- 记录信号数、可执行数、实际成交数、放弃原因。
- 计入佣金、税费、滑点、跳空、涨跌停无法成交、T+1。
- 单笔收益、平均盈亏比、最大不利与有利波动、回撤、持有天数。
- 按时间切分样本，滚动验证；不用未来数据定位结构或选参数。
- 样本须包含已退市股票；行业成分用历史归属。

### 17.3 消融对照

| 对照组 | 去掉的部分 | 要回答的问题 |
|---|---|---|
| 无 L1 | 否决门 | 否决门是否降低了尾部亏损 |
| 无温度 | m_sent 恒为 1 | 情绪乘数是否改善风险调整后收益 |
| 无板块确认 | L3 | 板块过滤是减少了错误信号还是只减少了信号 |
| 无模型层 | L8 | 模型标记是否有信息增量 |
| A1 vs A2 | 回调窗口口径 | 自适应窗口是否值得其复杂度 |
| V1 vs V2、X1 vs X2 | 退出变体 | 哪种退出在 A 股短趋势中更合适 |

### 17.4 观察期

- 只出报告、不下单 ≥ 4 个交易周，排查数据与流程错误。
- 短期观察结果不作为策略有效的证据。
